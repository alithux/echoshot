Write in Dhivehi on any PDF

Open a PDF or create a blank document. Tap Add text, then tap anywhere on the page to insert a right-to-left text box.

Text properties

Select an existing text box or use Add text to place Dhivehi on your PDF.

Drag the text directly on the page to reposition it.

Save text places it on the page. To download the finished document, use Export PDF at the top.

Faruma font

Faruma (Thaana glyphs) is included and loaded automatically. Optionally import another licensed Faruma font (.ttf/.otf/.woff).
